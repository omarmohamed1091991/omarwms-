# بيانات تسجيل الدخول للمدير

## إنشاء حساب مدير جديد

لإنشاء حساب مدير، اتبع الخطوات التالية:

### 1. التسجيل عبر الموقع (الطريقة الموصى بها)

1. اذهب إلى صفحة التسجيل: `/auth/sign-up`
2. أدخل البيانات التالية:
   - **البريد الإلكتروني**: `admin@whatsapp.com` (أو أي إيميل تريده)
   - **كلمة المرور**: `Admin@123456` (أو كلمة مرور قوية من اختيارك)
   - **رقم الجوال**: رقم WhatsApp الخاص بك (مثال: `+966500000000`)
   - **الاسم الكامل**: مدير النظام
3. انقر على "إنشاء حساب"

### 2. تسجيل الدخول

بعد إنشاء الحساب، يمكنك تسجيل الدخول من: `/auth/login`

- **البريد الإلكتروني**: الإيميل الذي استخدمته في التسجيل
- **كلمة المرور**: كلمة المرور التي اخترتها

## ملاحظات مهمة

- كل مستخدم في النظام لديه صفحاته وبياناته المنفصلة تماماً
- عند التسجيل، يتم إنشاء ملف تعريف وإعدادات تلقائياً لكل مستخدم
- يمكنك إنشاء عدة حسابات بإيميلات مختلفة
- كل مستخدم يحتاج لربط رقم WhatsApp الخاص به من صفحة الإعدادات
