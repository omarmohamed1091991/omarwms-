# نظام إرسال رسائل واتساب المتقدم

نظام متكامل لإدارة وإرسال رسائل واتساب الفردية والجماعية مع لوحة تحكم منفصلة لكل مستخدم.

## المميزات الرئيسية

### 1. نظام المصادقة والمستخدمين
- تسجيل دخول وإنشاء حساب آمن باستخدام Supabase Auth
- إنشاء ملف تعريف تلقائي لكل مستخدم جديد
- حماية كاملة للبيانات باستخدام Row Level Security (RLS)

### 2. لوحة التحكم
- إحصائيات شاملة لكل مستخدم
- عرض سريع للرسائل الفردية والجماعية
- متابعة حالة الحساب والرسائل غير المقروءة

### 3. الرسائل الفردية
- إرسال رسائل مخصصة لجهات اتصال محددة
- دعم النصوص والوسائط المتعددة
- تتبع حالة كل رسالة (قيد الإرسال، مرسلة، فشلت)
- سجل كامل للرسائل المرسلة

### 4. الرسائل الجماعية
- إنشاء حملات رسائل جماعية
- إضافة مئات المستلمين في قائمة واحدة
- تتبع تقدم الإرسال لكل حملة
- عرض تفاصيل كل مستلم وحالة رسالته

### 5. صندوق الوارد
- استقبال وعرض الرسائل الواردة
- تعليم الرسائل كمقروءة/غير مقروءة
- دعم النصوص والوسائط في الرسائل الواردة

### 6. الإعدادات
- **إعدادات الملف الشخصي**: تحديث الاسم ورقم الجوال
- **إعدادات واتساب API**: ربط الحساب مع WhatsApp Business API
- **الرد التلقائي**: تفعيل الرد التلقائي مع رسالة مخصصة
- **الإشعارات**: إضافة Webhook والبريد الإلكتروني للإشعارات

## البنية التقنية

### قاعدة البيانات (Supabase)
- `user_profiles`: معلومات المستخدمين الإضافية
- `individual_messages`: الرسائل الفردية
- `bulk_messages`: حملات الرسائل الجماعية
- `bulk_message_recipients`: مستلمي الحملات الجماعية
- `incoming_messages`: الرسائل الواردة
- `user_settings`: إعدادات كل مستخدم

### الأمان
- Row Level Security (RLS) على جميع الجداول
- كل مستخدم يرى بياناته فقط
- Middleware للتحقق من المصادقة
- حماية جميع API Routes

### التقنيات المستخدمة
- Next.js 16 (App Router)
- Supabase (Database + Auth)
- TypeScript
- Tailwind CSS v4
- shadcn/ui Components
- React 19

## التثبيت والاستخدام

### 1. نسخ المشروع
```bash
git clone <repository-url>
cd whatsapp-bulk-messages
npm install
```

### 2. إعداد متغيرات البيئة
المتغيرات مضافة تلقائياً من تكامل Supabase:
- `NEXT_PUBLIC_SUPABASE_URL`
- `NEXT_PUBLIC_SUPABASE_ANON_KEY`
- `SUPABASE_SERVICE_ROLE_KEY`

### 3. تشغيل المشروع
```bash
npm run dev
```

### 4. الوصول للنظام
- افتح المتصفح على `http://localhost:3000`
- أنشئ حساب جديد
- ابدأ باستخدام النظام

## الربط مع WhatsApp API

لتفعيل إرسال الرسائل الفعلي:

1. احصل على حساب WhatsApp Business API
2. أضف معرف النسخة (Instance ID) والرمز المميز (Token) في صفحة الإعدادات
3. قم بتحديث ملفات API في `app/api/send-message/route.ts` لإضافة الكود الفعلي للاتصال بـ API
